# 🎮 My Game Development Projects

Welcome to my game development repository! 🚀

This repository contains two interactive projects built while learning and practicing programming, along with my practice sheets and learning materials. These projects helped me explore game development, visual effects, user interaction, and creative coding.

## 🕹️ Project 1: Glitch Run

**Glitch Run** is a neon-themed, cyberpunk survival game where the world glitches as you fight to survive against waves of enemies.

### ✨ Features
- Neon-inspired visuals and glitch effects.
- Enemy waves with progressively increasing difficulty.
- Mouse aiming and shooting mechanics.
- Multiple weapon upgrades as you earn points.
- Health and shield pickups.
- Dash mechanics to escape dangerous situations.
- Increasing game speed and difficulty as your score rises.
- A score-based ending.

### 🎮 Controls
- **W / A / S / D** or **Arrow Keys** — Move.
- **Mouse** — Aim.
- **Left Mouse Button** — Shoot.
- **Space** — Dash.

### 🛠️ Technologies
- HTML
- CSS
- JavaScript
- HTML5 Canvas

## 🤖 Project 2: Jarvis Pronto Trail 2D

**Jarvis Pronto Trail 2D** is an interactive face-detection project that combines camera-based face tracking with fun, futuristic visual effects.

The project explores how face detection can be used to create an interactive experience, including effects inspired by futuristic AI assistants and superhero technology.

### ✨ Features
- Face detection using a camera.
- Interactive visual effects that respond to your face.
- Iron Man-inspired blaster effects.
- Text displayed above your head.
- Real-time visual overlays and face-tracking experiments.
- A playful, futuristic interface.

### 🛠️ Technologies
- HTML
- CSS
- JavaScript
- Camera-based face detection and tracking technologies

*Note: Camera access may require permission from your browser. Depending on the face-detection library used, the project may need to run through a local server or a secure HTTPS website.*

## 🚀 How to Run

### Glitch Run
1. Open the `Glitch Run` project folder.
2. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
3. Click the start button and begin playing!

### Jarvis Pronto Trail 2D
1. Open the `Jarvis Pronto Trail 2D` project folder.
2. Run the project using VS Code Live Server or another suitable local web server.
3. Allow camera access when prompted.
4. Try the face-tracking effects!
