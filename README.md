## 🕹️ 1. Glitch Run

**Glitch Run** is a neon-themed, cyberpunk survival game where the world glitches and enemies become increasingly challenging as you progress.

### ✨ Features
- Neon visuals and glitch effects.
- Waves of enemies with increasing difficulty.
- Mouse aiming and shooting.
- Multiple weapon upgrades.
- Health and shield pickups.
- Dash mechanics to avoid enemies.
- Increasing game speed as your score grows.
- A score-based ending.

### 🎮 Controls
- **W / A / S / D** or **Arrow Keys** — Move.
- **Mouse** — Aim.
- **Left Mouse Button** — Shoot.
- **Space** — Dash.

### 🛠️ Technologies
- HTML
- CSS
- JavaScript
- HTML5 Canvas

## 🤖 2. Jarvis Pronto Trail 2D

**Jarvis Pronto Trail 2D** is an interactive face-detection project inspired by futuristic AI assistants and superhero technology.

It uses camera-based face detection to explore interactive effects and make the experience more engaging.

### ✨ Features
- Camera-based face detection.
- Face-tracking visual effects.
- Iron Man-inspired blaster effects.
- Text displayed above the user's head.
- Interactive visual overlays.
- Experiments with real-time camera input.

### 🛠️ Technologies
- HTML
- CSS
- JavaScript
- Face-detection and tracking technologies

**Note:** Camera permission may be required. Depending on the implementation, the project may need to run through a local server or HTTPS.

## 🚀 How to Run the Projects

### Glitch Run
1. Open the `Glitch-Run` folder.
2. Open `index.html` in a browser, or run it using VS Code Live Server.
3. Click the start button and play!

### Jarvis Pronto Trail 2D
1. Open the `Jarvis-Pronto-Trail-2D` folder.
2. Run the project using VS Code Live Server or another suitable local server.
3. Allow camera access when prompted.
4. Try the interactive face effects!

### Flappy Bird & Other Mini-Games
1. Open the folder containing the mini-game you want to try.
2. Open its `index.html` file in a browser or use VS Code Live Server, depending on the project setup.
3. Follow the on-screen instructions to play.
